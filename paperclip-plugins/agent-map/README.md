# Agent Map · نقشهٔ ایجنت‌ها
نسخه 0.5.0 · به‌روزرسانی: 2026-11-21 18:15 به وقت برلین · تغییر: قدم صفر «روشن کردن نیت» قبل از هر برنامه (قاعدهٔ Siax، DECISIONS v1.5–1.7)؛ بدون اجازهٔ تازه

## چه می‌کند
- همان صفحهٔ تب «موکاپ افزونه» (چارت، نقشهٔ ذهنی، فهرست، ۲۴ ورک‌فلو با قدم‌به‌قدم، کارت دستورالعمل با فلوچارت، نگهبان، Ctrl+K، نقشهٔ کوچک، «از چشم این نقش»)، داخل Paperclip.
- وضعیت **زنده**: ایجنت‌های واقعی شرکت با چارت جور می‌شوند (metadata.orgId، یا id، یا نام فارسی) و وضعیت، مدل و هزینهٔ واقعی‌شان روی کارت می‌آید. نمای «فقط ایجنت‌های Paperclip» هم هست.
- **برنامه‌ریز پرونده** (مثلاً استخدام): پرسش‌نامه ← برنامه ← تیک تأیید شما ← تسک‌ها در **backlog** ساخته می‌شوند با پیش‌نیازها. هیچ ایجنتی خودکار شروع نمی‌کند.

- **هشدار بودجه** (ایده ۴): بالای ۸۰٪ بودجهٔ ماهانه، نوار هشدار و حلقهٔ قرمز روی کارت.
- **الگوی برنامه** (ایده ۵): برنامهٔ تأییدشده ذخیره می‌شود (حداکثر ۲۰)؛ یک کلیک پاسخ‌ها را برمی‌گرداند.
- **سناریو** (ایده ۱): خاموش کردن دپارتمان یا افزودن ایجنت Haiku/Sonnet/Opus → تعداد و هزینهٔ ماهانهٔ برآوردی قبل و بعد. فقط محاسبه، چیزی ساخته نمی‌شود.
- **ردیابی اجرا** (ایده ۲، تأیید Siax 2026-11-21 16:11 UTC): جدول ۳۰ روز اخیر برای هر ایجنت: تعداد اجرا، خطا، توکن ورودی/کش/خروجی، دلار، مدل، ۵ اجرای آخر (سبز/قرمز)، آخرین خطا. فقط خواندن از `heartbeat_runs` و `cost_events`. ستون‌ها با طرح پایگاه‌دادهٔ Paperclip تطبیق داده شد (هزینه = reported_cost_cents، ستون توکن کش وجود ندارد)؛ اگر غلط باشد صفحه می‌گوید «ردیابی در دسترس نیست» و بقیه کار می‌کند.
- **خروجی CSV** (ایده ۸): دکمهٔ خروجی، ۱۱۶ ایجنت با وضعیت زنده.

- **قدم صفر: روشن کردن نیت** (0.5): بانک ۱۶ سؤال پرونده؛ هر سؤال «چرا»، پاسخ پیشنهادی و منبع (مثلاً SHRM، Greenhouse، LinkedIn؛ وگرنه «بدون منبع»). ترتیب پیشنهاد: ۱) پرونده‌های قبلی خود شما (ذخیره در افزونه، با ذکر «از پروندهٔ …»)، ۲) استاندارد جهانی، ۳) پیش‌فرض. هر نوبت حداکثر ۴ سؤال، فقط بی‌جواب‌ها و مبهم‌ها. جواب مبهم («نمی‌دانم»، «؟»، «-») یا تضاد بین پرونده‌های قبلی = سؤال تکمیلی. خروجی: کارت نیت ۴ سطری + خلاصه؛ با تیک شما تأیید می‌شود و فقط بعد از آن برنامه‌ریز باز می‌شود. خلاصه در تسک اصلی پرونده نوشته می‌شود. پیش‌تنظیم «دستیار مدیرعامل» برای آزمون واقعی.
- خواندن تسک‌های قبلی Paperclip (نه فقط پرونده‌های همین افزونه) اجازهٔ `issues.read` می‌خواهد که هنوز اضافه نشده.
