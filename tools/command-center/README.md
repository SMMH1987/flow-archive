# مرکز فرماندهی (MVP)

یک بوم مثل n8n برای همهٔ پروژه‌ها. فقط می‌خواند و لینک می‌دهد؛ ویرایش فلو در استودیو می‌ماند.

## اجرا
- با Docker: روی `start.bat` دوبار کلیک کن، بعد http://127.0.0.1:8090
- بدون Docker: `python server.py` (فقط Python و git لازم است)

هر پوشه در `D:\AI\Claude-Ai 1\Code` که فایل `cc.json` داشته باشد، روی بوم می‌آید.

## cc.json (تنها خانهٔ اطلاعات هر پروژه برای این صفحه)
```json
{"name":"...", "role":"...", "status":"...", "shot":"مسیر عکس آخر",
 "steps":[{"id":"case","icon":"📥","title":"...","state":"ok|gate|bad|","url":"اختیاری"}],
 "links":[{"from":"case","to":"flow-archive:rules","label":"...","via":"MCP"}],
 "secrets":["فقط نام کلید، هرگز مقدار"]}
```

## امکانات
- نسخه‌ها از `git log`. «برگرداندن» = `git revert`: یک کامیت تازه می‌سازد و تاریخچه پاک نمی‌شود.
- قفل فایل = فایل `.cc-locks` + هوک pre-commit که کامیتِ فایل قفل را رد می‌کند (برای همهٔ ابزارها: Claude، Codex، دستی).
- همان `docker-compose.yml` روی سرور هم اجرا می‌شود؛ فقط `CODE_ROOT` عوض می‌شود.
