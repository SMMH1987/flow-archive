# چارت سازمانی جهانی + لایهٔ ایران
- مدل: `org-global.c4` (یک فایل، SSOT). نمای `world` = جهانی، `iran_layer` = جهانی + ۲۱ ماژول ایران (تگ `#loc_ir`).
- ۱۳ بخش / ۵۶ واحد طبق APQC PCF (۱۳ دسته) و زنجیرهٔ ارزش پورتر (تگ primary/support). منبع هر بخش در `technology`.
- انتخاب لایه: `org-global.rules.yaml` (جدول تصمیم، طبق STANDARD-PROCESS-BUILD). کشور دیگر = یک ردیف + یک بلوک `extend`.
- هر واحد: ask/auto/gate + `external: yes|no|?`. هرچه پول/حقوقی/انتشار = gate.
- ⚠️ نام‌ها و منابع از حافظه‌اند (تأییدنشده). جزئیات حقوقی/مالیاتی ایران → پروژهٔ حق‌پرس.
- قدم بعد پیشنهادی: هر واحد → زیرفلوی کاری (مثل recruitment.c4 برای جذب).
