# نیت قفل‌شده — flow-archive

قفل: ۲۰۲۶-۱۰-۲۹ · تغییر فقط با گفتهٔ صریح کاربر (نسخهٔ قبلی با تاریخ نگه داشته شود)

- 🎯 **نیت:** هر فرایند (مثل استخدام فروشندهٔ درصدی) به‌صورت یک **ورک‌فلوی مرحله‌ای** که Claude آن را دستورالعمل بخواند و اجرا کند؛ هر مرحله `skill · out · after` دارد، بخش‌ها مرز دارند، و شاخه‌ها با نتیجهٔ skill انتخاب می‌شوند.
- ✅ **تمام‌شده یعنی:** نمای **Map جعبه‌ای جمع‌وبازشو** (اول کلیات، با کلیک جزئیات) — توسعه روی **LikeC4** (C4)؛ رنگ هر قدم = نوع `after` (ask نارنجی · auto سبز · gate قرمز · route بنفش)؛ در هر مرحله find-skills بهترین skill را **پیشنهاد** می‌دهد و کاربر **تأیید** می‌کند؛ «بساز» = **لینک آنلاین تست‌شده**.
- 🚫 **نه:** فلوچارت تنها به‌عنوان خروجی نهایی؛ نصب خودکار skill بیرونی بدون «بله»؛ انتشار بدون اجازه.
- 📍 **کجا / برای کی:** برای خود کاربر؛ آنلاین روی GitHub Pages مخزن `SMMH1987/flow-archive`؛ اجراکننده = skill `cc-flow-run`.
